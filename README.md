# simple-interest-calculator
Simple Interest Calculator

Project Overview

This project is a simple Bash-based calculator that computes simple interest using the following inputs:

Principal amount

Rate of interest

Time period

Formula

Simple Interest = (Principal × Rate × Time) / 100

The calculator takes the required values from the user and displays the calculated simple interest.

How to Run

Open a terminal in the project directory.

Make the script executable:

chmod +x simple-interest.sh

Run the calculator:

./simple-interest.sh

Enter the principal amount, rate of interest, and time period when prompted.

Example

Enter the principal amount:
10000
Enter the rate of interest:
5
Enter the time period:
2

Simple Interest: 1000
